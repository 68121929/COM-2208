# ตอบคำถาม 3 ข้อ #
1.ความหมายของเทคโนโลยี 
# เทคโนโลยี คือ การนำความรู้ทางวิทยาศาสตร์ ความรู้ทางวิชาการ ทักษะ และวิธีการต่าง ๆ มาประยุกต์ใช้เพื่อสร้างเครื่องมือ อุปกรณ์ ระบบ หรือกระบวนการที่ช่วยแก้ปัญหาและอำนวยความสะดวกในการดำเนินชีวิตของมนุษย์ #
2.นวัตกรรม (Innovation)
# นวัตกรรม คือ การนำแนวคิดใหม่ หรือแนวคิดเดิมที่ได้รับการปรับปรุงมาพัฒนาเป็นผลิตภัณฑ์ บริการ กระบวนการ หรือวิธีการทำงานที่สามารถนำไปใช้ได้จริง และสร้างคุณค่าหรือประโยชน์ให้แก่ผู้ใช้หรือสังคม
# แอปพลิเคชันสั่งอาหาร ช่วยให้ผู้บริโภคสั่งอาหารได้สะดวก
# บรรจุภัณฑ์ย่อยสลายได้ ช่วยลดปัญหาขยะพลาสติก
# ระบบชำระเงินผ่าน QR Code ช่วยให้การจ่ายเงินรวดเร็วขึ้น #
3.Design Thinking (การคิดเชิงออกแบบ) 
#  กระบวนการคิดเพื่อแก้ไขปัญหาอย่างสร้างสรรค์ โดยให้ความสำคัญกับความต้องการและประสบการณ์ของผู้ใช้เป็นหลัก 
# เพื่อพัฒนาผลิตภัณฑ์ บริการ หรือวิธีการแก้ปัญหาที่ตอบโจทย์ผู้ใช้ได้จริง #
